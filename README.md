# 온코푸드 (OncoFood)

암 환자를 위한 근거 기반 식이·영양 도우미. 한국에서 실제로 먹는 음식과 약국에서 파는 영양제를
암종·치료 시기·증상에 맞춰 판단하고, 하루 식단을 구성해 준다.

설치 없이 브라우저에서 쓸 수 있고, 홈 화면에 추가하면 오프라인에서도 동작한다.
입력한 정보는 기기 안에만 저장되며 서버로 전송되지 않는다.

## 무엇을 하는 앱인가

| 화면 | 하는 일 |
| --- | --- |
| 음식 찾기 | 412종의 한국 음식·식재료를 검색하고, 이 환자에게 어떤 의미인지 확인 |
| 분석 | 담은 음식의 영양소 합계, 목표 대비 달성률, 경고와 약물 상호작용 |
| 식단 | 고른 음식을 바탕으로 부족한 부분을 채운 하루 메뉴 구성 |
| 영양제 | 약국 유통 영양제 35종의 성분 정량화와 암종별 적합성 |
| 가이드 | 암종별 영양 목표·권고 전문과 시기별 실무 지침 |

## 설계 원칙

1. **근거 없는 권고는 넣지 않는다.** 모든 임상 권고에 근거 수준(A/B/C/G)과 출처를 붙였다.
   근거가 엇갈리는 주제(오메가-3와 악액질, 리코펜과 전립선암 등)는 그 사실 자체를 적었다.
2. **암종별로 방향이 반대인 것을 그대로 보여준다.** 칼슘·유제품은 대장암에서는 보호 인자이고
   전립선암에서는 주의 대상이다. 이런 차이를 뭉개지 않는다.
3. **시기가 암종보다 중요한 경우가 많다.** 대장암에서 식이섬유는 회복기에는 권장이지만
   수술 직후에는 피해야 한다. 규칙에 치료 시기를 붙여 이 역전을 표현한다.
4. **성분은 100 g 기준으로 저장하고 제공량은 따로 둔다.** 사용자가 몇 인분을 고르든
   계산식은 하나로 유지된다.
5. **규칙은 식품 id 가 아니라 태그로 매칭한다.** 식품이 늘어도 규칙은 늘지 않는다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5175
npm run build
```

## 배포

`main` 에 push 하면 GitHub Actions 가 빌드해 GitHub Pages 로 게시한다.
저장소 Settings → Pages → Source 를 **GitHub Actions** 로 설정해 두어야 한다.

하위 경로 배포를 위해 빌드 시 `ONCOFOOD_BASE` 를 저장소 이름으로 넘긴다.

```bash
ONCOFOOD_BASE=/oncofood-app/ npm run build
```

## 구조

```
src/
  data/
    types.ts          스키마 — 모든 데이터 구조의 단일 출처
    foods/            식품 (식품군별 파일)
    cancers/          암종별 프로필 10종
    supplements.ts    영양제
    commonRules.ts    암종 무관 공통 규칙
    conditionRules.ts 증상별 규칙
    interactions.ts   약물 × 식품/영양제
    references.ts     참고문헌
  engine/
    nutrition.ts      영양소 합산, 섭취기준(KDRIs), 개인별 목표
    rules.ts          규칙 매칭과 평가
    menu.ts           하루 식단 구성
  components/         화면
```

## 한계

- 영양성분은 대표값이다. 조리법과 제품에 따라 실제 값은 달라진다.
- 영양제 함량은 제조사가 처방을 바꾸면 달라진다. 실제 상담에서는 라벨을 확인해야 한다.
- 이 앱은 진료·처방·영양 상담을 대체하지 않는다.
