## 무엇을 말하는가

기존 선택지(병원 안내문 · 검색 · 식단 배송 · 일반 식단 앱)에 공통으로 비어 있는 칸을 짚고,
하루차림만 하는 다섯 가지를 세웁니다. 그중 셋은 국내에서 유일합니다.

1. **참고 문헌 79종 전부 원문 대조** — "지침에 따르면" 이 아니라 실제로 받아 맞춰 봄
2. **문장마다 근거 등급 · "아직 모릅니다" 를 적음**
3. **약–음식 상호작용 약제 18종 · 규칙 21개**
4. 한국 밥상·한국 기준 위에서 판단
5. 팔지 않고 기록을 가져가지 않음

가장 설득력이 큰 부분은 **「흔히 도는 정보와 하루차림의 답」** 여섯 쌍입니다.
호중구감소증 식단, 유방암과 콩, 채소 400 g, 가공육 1군, 수술 후 죽, 항산화제 —
모두 진료실에서 실제로 반복되는 오해이고, 오른쪽이 원문을 확인한 뒤의 답입니다.
