## 무엇을 말하는가

기존 선택지(병원 안내문 · 검색 · 식단 배송 · 일반 식단 앱)에 공통으로 비어 있는 칸을 짚고,
하루차림만 하는 다섯 가지를 세웁니다. 그중 셋은 국내에서 유일합니다.

1. **참고 문헌 79종 전부 원문 대조** — "지침에 따르면" 이 아니라 실제로 받아 맞춰 봄
2. **문장마다 근거 등급 · "아직 모릅니다" 를 적음**
3. **약–음식 상호작용 약제 18종 · 규칙 21개**
4. 한국 밥상·한국 기준 위에서 판단
5. 팔지 않고 기록을 가져가지 않음

가장 설득력이 큰 부분은 **「흔히 도는 정보와 하루차림의 답」** 여섯 쌍입니다.
호중구감소증 식단, 유방암과 콩, 채소 400 g, 가공육 1군, 수술 후 죽, 항산화제 —
모두 진료실에서 실제로 반복되는 오해이고, 오른쪽이 원문을 확인한 뒤의 답입니다.

## 주의

- 특정 제품을 지목해 깎아내리지 않습니다. **유형별**로만 비교합니다.
  확인할 수 없는 남의 제품을 평가하는 것은 이 앱의 원칙과 맞지 않습니다.
- "국내 유일" 표기는 세 항목에만 붙였습니다. 근거를 댈 수 있는 범위에서만 쓰십시오.
- 수치(144·79·18,000·270,000·3,531,402)는 실제 값입니다. 바뀌면 함께 고치십시오.

## 발표 자료 — `하루차림-발표.html`

열두 장짜리 발표. 브라우저로 열어 → 키·스페이스·화면 오른쪽으로 넘기고, **F** 로 전체 화면.
숫자는 장이 켜질 때 0 에서 세어 올라가고, 막대·화살표가 차례로 그려집니다.
인쇄하면 한 장에 한 쪽씩 나오므로 나눠 드릴 자료로도 쓸 수 있습니다.

| 강조한 숫자 | 값 | 어디서 셌나 |
|---|---|---|
| 식품 데이터 | 291,378건 (기본 18,298 + 가공식품 273,080) | `FOODS` · `public/data/foods-extended.json` |
| 판단 엔진 | 6개 | `src/engine/` |
| 임상 규칙 | 144개 (영양 123 + 상호작용 21) · 근거 A16 B25 C23 G59 | `src/data/*Rules.ts` · `interactions.ts` |
| 검사한 추천 | 3,531,402건 (3,000명 × 90일) · 피해야 할 것 추천 0건 | `scripts/checks/bigrun.ts` (2026-09) |

숫자를 바꿀 일이 생기면(자료를 새로 받거나 규칙을 더하면) 위 자리에서 다시 세어 고치십시오.
기본 식품과 가공식품은 출처가 다른 별개 기록이라 더했고, 이름이 같은 1,985건도 서로 다른 기록입니다.
바코드(230,027)와 시판 영양제(45,618)는 식품 합계에 넣지 않았습니다.
