# 환자가 앱을 써도 안전한가 — 재검토와 고친 것 (2026-10-15)

> 방법: 앱 엔진을 직접 돌리는 독립 검토(위험 시나리오 15가지 × 21일 식단, 음식 29만 종 이름 훑기, 영양제·극단 입력)
> 그리고 사용자 보고(추천 식단의 에너지·섬유 '넘음', 단백질 '주의', 다시 구성이 듣지 않음).
> 결과: **critical 1 · high 9 · medium 9 · low 6.** critical·high 는 모두 고쳤습니다(알레르기는 같은 날 오후 기능으로 넣음). medium·low 는 아래 4절에 남깁니다.

## 1. 결론

**규칙이 말한 '피하세요'를 식단이 어기는 일은 없었습니다** — 15가지 고위험 시나리오 21일 식단에서 0건, 대규모 시험(2,000명 × 90일)에서도 0건입니다.
위험은 규칙 자체보다 **규칙이 닿지 못하는 자리**에 있었습니다.

- 질감 같은 '규칙이 아예 없는 영역'
- 공공데이터처럼 '태그가 안 붙은 음식'
- 와파린처럼 '같은 상태를 두 칸으로 고를 수 있는 곳'

이번에 그 자리들을 메웠습니다.

## 2. 사용자 보고 — 추천 식단 균형과 '다시 구성'

| 문제 | 원인 | 고친 것 | 결과 |
|---|---|---|---|
| 에너지·섬유 '넘음', 단백질 '주의' | 상을 갖추려고 단계마다 조금씩 열어 준 폭(밥 한 공기, 반찬 8 %, 두 번째 반찬)이 하루에서 쌓임 | 다 차린 상에서 **넘친 값만 덜어 내는 단계**(앱이 고른 것만, 반 접시씩, 다른 값이 하단 아래로 내려가지 않게, 상이 무너지지 않게) | 열량·단백질·섬유 모두 적정인 상 **33 % → 88 %**, 열량 상단 초과 **33 % → 0.1 %** |
| '다시 구성'이 먹통 | '추천 담기'를 누르면 모든 음식이 '내가 담음'이 되고, 다시 구성은 담은 것을 건드리지 않음 — 같은 상을 내놓고도 "2번째 안입니다"라고 적었음 | 바꿀 것이 없으면 **그렇다고 밝히고** 내 식단으로 가는 단추를 둠. 담은 것이 있으면 "담으신 N가지는 그대로 두고 나머지만 바꿉니다"를 미리 적음 | 화면에서 확인 |
| 담는 순간 목표를 넘음 | '추천 담기'가 양을 넘기지 않아 **반 공기가 한 공기로** 담겼음 | 추천에 적힌 양 그대로 담음(한 가지씩 담기도 같음) | 화면에서 확인 — 반 공기 4건이 그대로 담김 |
| 다른 탭에 다녀오면 보던 안이 사라짐 | 화면이 내려가면 안 목록이 지워졌음 | 조건이 같으면 보던 안을 이어 보임 | 화면에서 확인 — 3번째 안 그대로, '이전 안' 동작 |
| 섬유 막대만 빨강 | 위 막대는 목표 상단을 넘으면 '넘음', 아래 점검은 "채우고 넘었습니다(좋음)" — 같은 화면이 두 말 | 저잔사 시기가 아니면 섬유도 단백질처럼 '넘어도 괜찮은 쪽'으로 칠함 | — |

## 3. 안전 검토에서 고친 것 (critical·high)

| 등급 | 문제 | 고친 것 |
|---|---|---|
| critical | 연하곤란 식단에 생배·찹쌀밥·밤·꽃게·단팥빵이 오름(질감으로 거르는 단계가 없었음). '부드러움' 태그가 "헌 입에 덜 아픈 것"이라 빵·족발·냉면·국밥에도 붙어 있었음 | 연하곤란이면 **삼키기 쉬운 질감만** 식단에 올림(`swallowSafe` 한 곳). 질감이 맞지 않는 음식에는 '권장'을 붙이지 않음. 식단 머리에 "연하 평가에서 정해 주신 단계를 먼저" 안내 |
| high | 공공데이터 떡 760종 중 757종에 '점착성' 없음 | 떡·찹쌀·인절미·송편 등에 이름으로 '점착성'(떡갈비·떡맛 과자 제외) |
| high | 호중구 시기에 연어알·성게·생간이 '권장', 굴·해삼·천엽 무표시 | 날로 먹는 해산물·내장 '생것'에 '날것' 이름표 → '피하세요'. 익혀 먹을 생것 재료(쇠고기 생것 등)는 '권장'만 지움. 연어롤·포케·사케동도 날것으로 |
| high | 간경변 비브리오 경고가 다섯 가지 이름에만 걸림 | '날해산물' 태그로 넓힘. 간암이 아니어도 '간성뇌증 위험'을 고르면 같은 경고 |
| high | 공공데이터에 1회 나트륨 보정이 없어 1회 600~800 mg 음식의 63 %가 복수·고혈압·점막염 규칙을 빠져나감 | 손검토 음식과 같은 잣대(1회 400 mg)를 공공데이터에도 |
| high | 와파린을 증상 칸으로만 고르면 오메가-3 '권장', 은행잎 '주의'(약 칸으로 고르면 '주의'·'피하세요') | 두 칸을 **연동**(하나를 켜면 둘 다). 엔진도 증상 칸을 약으로 읽음 |
| high | 응급 안내가 없음 | 식단 위에 상태별 "이럴 때는 식단보다 병원이 먼저입니다" — 열 38 ℃·출혈·탈수·사레·장폐색 |
| high | 알레르기를 묻지 않음 | **알레르기 기능 추가** — 식약처 「식품등의 표시기준」 알레르기 유발물질 표시대상 19항목을 처음 설정(식성 단계)과 내 정보에서 고름. 고른 것이 이름에 보이는 음식은 '피하세요'(근거 등급 대신 '내가 고른 알레르기'로 표시)·추천 식단에서 뺌·담은 것은 '빼는 것이 좋겠습니다'로. **이름으로 찾는다**는 한계를 화면에 함께 적음(빵의 달걀·우유, 간장의 밀·대두, 해물의 새우·오징어·조개는 넓게 잡음). 처리방침 '수집하지 않는 항목'에 알레르기 추가(기기에만 저장) |
| high | 옥살리플라틴 + 점막염에 아이스크림 '권장', 이유 글은 얼음 물기를 소개 | 찬 음식(아이스크림·빙수·냉면·아이스 음료) '주의' — 출처는 옥살리플라틴 허가사항. 옥살리플라틴이면 "차가운 음식이 견디기 쉽다"를 끔 |
| high | 신기능저하 + 스타후르츠(오렴자·카람볼라) 판정 없음 | '피하세요' 추가 — Lakmal 2021 종설(원문 대조), 근거 C |

**영구 검사:** 위 항목은 모두 `scripts/checks/safety.ts`에 못 박았습니다. 다시 생기면 검사가 실패합니다.
