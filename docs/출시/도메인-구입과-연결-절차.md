# 도메인 구입과 연결 — 따라 하기

작성 2026년 8월 31일 · 대상 `harucharim.com`

---

## 0. 왜 필요한가 (한 문단)

구글 플레이에 TWA 방식으로 올리려면 `https://도메인/.well-known/assetlinks.json` 파일이
**주소의 맨 뿌리에** 있어야 합니다. 지금은 `github.io/harucharim-app/` 이라는 남의 집 하위 방이라
뿌리에 파일을 놓을 자리 자체가 없습니다. 이것이 도메인이 필요한 결정적인 이유입니다.

덤 — 주소가 짧아지고, 도메인 메일을 쓸 수 있고(처리방침에 개인 gmail을 안 써도 됩니다),
나중에 호스팅을 옮겨도 주소가 그대로 남습니다.

## 1. 무엇을 살 것인가

**`harucharim.com`** 을 권합니다. 2026년 8월 31일 조회 기준으로 아직 살아 있습니다.

| 후보 | 판단 |
|---|---|
| **harucharim.com** | **권함.** 어디서나 값이 싸고 개인정보 보호가 기본으로 붙습니다 |
| harucharim.kr / .co.kr | 국내 신뢰감은 있으나 **개인 등록자의 정보 공개 범위가 더 넓습니다.** 개인 명의로 등록하실 것을 생각하면 부담 |
| harucharim.app | 구글이 운영. HTTPS가 강제되어 PWA에 어울리지만 국내 인지도가 낮음 |
| 하루차림.한국 | 링크를 복사하면 `xn--` 로 깨져 보입니다. 권하지 않음 |

여력이 되시면 `.kr` 을 방어용으로 같이 잡아 `.com` 으로 넘기는 방법도 흔합니다.
필수는 아닙니다.

> 상표 출원을 생각하고 계시니 도메인과 상표를 **같은 이름**으로 두시는 편이 좋습니다.

## 3. 구입할 때 (가비아 기준)

1. gabia.com 접속 → 검색창에 `harucharim.com` 입력 → 등록 가능 확인
2. 장바구니에 담고 **등록 기간**을 고릅니다
   - 1년도 되지만 **여러 해를 한 번에** 등록하면 갱신을 잊을 위험이 없어집니다
   - 도메인이 만료되면 **앱 전체가 죽습니다.** 이것이 가장 흔한 사고입니다
3. 아래 두 가지를 **반드시** 켭니다
   - [ ] **개인정보 보호(WHOIS 보호)** — 켜지 않으면 이름·주소·전화번호가 공개 조회됩니다
   - [ ] **자동 갱신**
4. 결제. 결제 후 등록 카드가 만료되지 않게 관리하십시오

> 구입은 직접 하셔야 합니다. 제가 대신 결제할 수 없습니다.

## 4. DNS 레코드 넣기 (선생님이 하실 것)

가비아 → **My가비아 → 도메인 → 관리 → DNS 정보 → DNS 설정(레코드 수정)**

아래 다섯 줄을 넣습니다. TTL은 기본값 그대로 두시면 됩니다.

| 타입 | 호스트 | 값 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `rohkwangwon-lang.github.io.` |

- `@` 는 "도메인 자체(harucharim.com)"를 뜻합니다. 가비아 화면에 따라 빈칸으로 두는 곳도 있습니다
- CNAME 값 **끝의 점(`.`)** 을 요구하는 화면이 있습니다. 저장이 안 되면 점을 빼거나 붙여 보십시오
- IPv6도 넣고 싶으시면 AAAA 레코드로 아래 넷을 더합니다 (선택 사항입니다)

```
2606:50c0:8000::153
2606:50c0:8001::153
2606:50c0:8002::153
2606:50c0:8003::153
```

**반영에 시간이 걸립니다.** 보통 10분~1시간, 길면 하루입니다. 바로 안 되어도 정상입니다.

## 5. GitHub 설정 (선생님이 하실 것)

1. https://github.com/rohkwangwon-lang/harucharim-app 접속
2. **Settings** 탭 → 왼쪽 메뉴 **Pages**
3. **Custom domain** 칸에 `harucharim.com` 입력 → **Save**
4. 아래에 "DNS check in progress" 가 뜹니다. 초록 체크가 될 때까지 기다립니다
5. 초록 체크가 뜨면 **Enforce HTTPS** 를 체크합니다
   - 인증서 발급에 15분~24시간 걸립니다. 체크박스가 회색이면 아직 발급 전입니다

## 6. 제가 할 것 (말씀만 주시면 한 번에)

| 무엇 | 왜 |
|---|---|
| 배포 설정에서 `HARUCHARIM_BASE` 제거 | 주소 뿌리가 `/` 가 되고 PWA 시작주소·범위·서비스워커 경로가 따라옵니다. `vite.config.ts` 가 이미 환경변수로 받게 되어 있어 한 줄이면 됩니다 |
| `public/CNAME` 파일 생성 | **없으면 배포할 때마다 5번에서 하신 설정이 지워집니다.** 가장 흔히 놓치는 곳입니다 |
| `public/.well-known/assetlinks.json` 자리 마련 | TWA 서명키 지문이 나온 뒤 채웁니다 |
| 처리방침·질의서의 주소와 문의처 갱신 | 개인 gmail 대신 도메인 메일로 바꾸실 수 있습니다 |

## 7. 잘 되었는지 확인하는 법

터미널에서 (Mac의 '터미널' 앱):

```bash
dig +short harucharim.com
```

`185.199.108.153` 같은 값 넷이 나오면 DNS는 된 것입니다.

```bash
curl -sI https://harucharim.com | head -3
```

`HTTP/2 200` 이 나오면 사이트가 뜬 것입니다.

브라우저에서 `https://harucharim.com` 을 열어 자물쇠 표시가 보이면 끝입니다.

---

## 8. 흔한 사고 다섯 가지

1. **`public/CNAME` 을 안 만들어 설정이 배포 때마다 지워짐** — 위 6번으로 막습니다
2. **도메인 만료로 앱 전체가 죽음** — 자동갱신 + 카드 관리. 여러 해 등록이 가장 안전합니다
3. **개인정보 보호를 안 켜서 집주소·전화번호가 공개됨** — 구입 시점에 켜는 것이 가장 쉽습니다
4. **DNS가 바로 안 된다고 값을 이리저리 바꿈** — 한 번 넣고 최소 1시간은 기다리십시오
5. **Enforce HTTPS를 안 켬** — 켜지 않으면 `http://` 로도 열리고, PWA 설치가 막힙니다

## 9. 옮기기 전에 반드시 아셔야 할 것

**주소가 바뀌면 브라우저는 완전히 다른 사이트로 봅니다.**

`github.io` 에 저장된 식단 기록과 체중은 새 도메인으로 **넘어가지 않습니다.**
이 앱은 건강 정보를 기기 안에만 두고 서버로 보내지 않으며, 기기 이전 기능도 아직 없기 때문입니다.

지금 쓰고 계신 분이 있다면 기록이 사라진 것처럼 보입니다.
**그래서 출시 전인 지금이 옮길 가장 좋은 때입니다.**

옮긴 뒤에 이용자가 생기고 나서 또 옮기는 일은 없어야 합니다 — 도메인은 한 번에 정하십시오.
