- `capacitor.config.ts` · `ios/` — 번들 ID **`com.harucharim.app`**(안드로이드 패키지와 같음), 이름 **하루차림**.

### 왜 1단계 로그인은 이메일만인가
- 카카오·구글 로그인을 두면 애플은 **'Apple로 로그인'도 함께** 두라고 합니다(지침 4.8). 그러면 계정 삭제 때 **애플 토큰 철회**까지 서버에 붙여야 합니다.
- 구글은 앱 안에 띄운 로그인 창을 막습니다 — 사파리 창으로 열고 앱으로 돌려받는 장치가 따로 필요합니다.
- 이메일만 두면 둘 다 해당하지 않아 첫 심사가 단순해집니다. 기록은 기기 안에 있으므로 로그인 방법이 달라도 쓰시는 데 차이가 없습니다.
- **2단계**(첫 승인 뒤): Apple로 로그인 + 카카오·구글(사파리 창 방식) + 토큰 철회.

## 2. Xcode 설치 (선생님) — ✅ 완료

> 터미널에서는 `DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer` 를 붙여 씁니다(맥 기본값이 명령줄 도구를 가리켜도 sudo 없이 됨).

1. 맥의 **App Store** 앱 → 'Xcode' 검색 → 받기(무료, 15 GB 안팎, 한두 시간).
2. 다 받으면 Xcode 를 **한 번 여시고** 추가 구성요소 설치·약관 동의를 마쳐 주세요.
3. 끝나면 말씀만 해 주세요. 그 뒤로는 제가 터미널에서 `npm run ios:sync` → 시뮬레이터 빌드·점검을 합니다.

## 3. Apple Developer Program 가입 (선생님)

- https://developer.apple.com/programs/enroll/ → **개인(Individual)** · 연 **99달러**(결제는 선생님이).
- Apple ID 에 **이중 인증**이 켜져 있어야 합니다.
- **개인 계정은 앱스토어 '판매자'에 실명이 공개됩니다**(구글 개인 계정과 다름). 실명이 신뢰에 도움이 된다고 정하신 바와 맞지만, 알고 가입하시는 게 좋습니다.
- 수익 기능을 켤 때는 계정 명의(사업자·법인)를 먼저 정리합니다 — 개인→법인 이전은 번거롭습니다.

## 4. Xcode 서명 (선생님, 한 번만)

1. 터미널에서 `npm run ios:open` (Xcode 로 프로젝트가 열림).
2. Xcode → Settings → Accounts → **+** → Apple ID 로그인(비밀번호는 선생님이 직접).
3. 왼쪽 App → Signing & Capabilities → **Team** 에서 선생님 이름 고르기. 'Automatically manage signing' 켜 둠.
4. 기능(Capability) 추가는 1단계에는 필요 없습니다(알림은 '로컬 알림'이라 푸시 설정 불필요).

## 5. 빌드·올리기 (함께)

```
npm run ios:sync      # 웹 빌드 → 아이폰 프로젝트로 복사 → 웹 전용 파일 덜어 냄
npm run ios:open      # Xcode 열기
```
Xcode: 위쪽 기기 고르기 **Any iOS Device (arm64)** → Product → **Archive** → Distribute App → App Store Connect → Upload.
올린 빌드는 15~30분 뒤 App Store Connect → TestFlight 에 보입니다. 선생님 아이폰에 TestFlight 앱을 깔아 먼저 써 보십시오.

판 번호: 처음 **1.0 (1)**. 다시 올릴 때마다 Xcode → App → General 의 Build 를 1씩 올립니다.

## 8. 다시 올리는 법 (화면을 고친 뒤)

웹·안드로이드는 배포하면 바로 바뀌지만, 아이폰 앱은 **새 빌드를 올려 심사**를 받아야 합니다.
```
npm run ios:sync && npm run ios:open    # Build 번호 +1 → Archive → Upload
```
주간 근거 페이지처럼 자주 바뀌는 것이 생기면 '앱 안 자료 + 인터넷에서 새 자료 받기' 구조를 그때 검토합니다.
