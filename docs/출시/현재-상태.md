### 2-1. 10월 13일 자가시험에서 나온 것

평소 검사는 늘 같은 난수(씨앗)로 돕니다. 이번에는 씨앗을 바꿔 가며, 그리고 실제 화면을 열어 가며 돌렸습니다.

| 무엇을 | 얼마나 | 결과 |
|---|---|---|
| 식단 짜기 (새 씨앗 4개) | 가상 환자 8,000명 × 90일 = 72만 일 | 피해야 할 것을 권한 날 0 · 빈 끼니 0 · 합계 오류 0 |
| 작은 검사 13종 (새 씨앗 6개) | 78회 | 2가지 새로 발견 → 1가지 고침, 1가지 보고 |
| 상식 검사 (새로 만듦) | 음식 약 29만 종 | 안전 구멍 여럿 발견 → 고침 |
| 화면 시험 (새로 만듦) | 상태 240가지 × 탭 7개 (폰 폭 360·430) | 멈춤·깨진 글자·넘침 발견 → 고침, 다시 돌려 0건 |

**고친 것 (환자분께 보이던 것)**

- 간장게장·새우장·연어장·생굴무침이 호중구감소 시기에 경고 없이 지나감 → 전부 '피하세요'
- 젓갈·장아찌·단무지·굴비가 위암 환자분께 경고 없이 지나감 → 경고
- 젓갈·햄 같은 염장·가공육이 "단백질이 많아 권장"으로 뜸 → 권장에서 뺌
- 청국장·케일·시금치에 와파린 경고가 안 붙음 → 붙임
- "카페시타빈–와파린" 안내가 와파린을 안 드시는 분께도 뜸 → 둘 다 고르신 분께만

## 3. 남은 일 — 순서대로

### ① 식약처에 질의서 내기 ← **지금 여기**

- 낼 문서는 다 되어 있습니다(18쪽 PDF).
- 내기 전에 **4항만 직접 읽어 주십시오.** 앱이 실제로 하는 말을 숨김없이 적은 부분입니다.
- 창구는 전화 한 통으로 확정: 식약처 의료기기 정책 문의 **1577-1255**
- 따라 하기: `docs/법무/식약처-질의-제출-방법.md`
- 회신을 기다리는 동안 아래 ②~⑤는 **진행하셔도 됩니다.** 공개 출시(⑦)만 회신 뒤로 미룹니다.

### ② Supabase 주소 설정 확인 (1분)

Supabase → `oncofood` → Authentication → URL Configuration 에서 Site URL 이 `https://harucharim.com` 인지.
가입 확인 편지의 단추가 이 주소로 사람을 돌려보냅니다. 제가 밖에서는 볼 수 없는 값입니다.

### ③ 가입 확인 메일 연결 (SMTP) — **아직 안 됨**

- 지금은 Supabase 기본 발송기라 **시간당 몇 통**만 나갑니다. 시험 삼아 한두 명 가입하는 데는 지장 없지만, 공개하면 가입이 막힙니다.
- 할 일: Resend 가입 → 가비아에 DNS 3~4줄 → Supabase 에 연결 → 한국어 편지 서식 붙여 넣기
- 10월 13일 확인: 가비아에 Resend 용 DNS 가 아직 없습니다.
- 따라 하기: `docs/출시/SMTP-연결-절차.md`

### ④ 심사용 계정 만들기

- 앱에서 이메일로 가입: **`rohkwangwon+review@gmail.com`** (편지는 평소 메일함으로 옵니다)
- ⚠️ `rohkwangwon@gmail.com` · `drnkw@hotmail.com` 그대로는 안 됩니다 — 관리자 주소라 심사자가 문의 관리 화면을 보게 됩니다.
- 식약처가 심사용 계정을 요청할 때도 이 계정을 씁니다.

### ⑤ 구글 플레이에 올릴 파일 만들기 — **아직 안 됨**

- pwabuilder.com → `https://harucharim.com` → Package For Stores → Android
- Package ID 는 반드시 **`com.harucharim.app`**
- 받은 zip 의 `signing.keystore` 와 `signing-key-info.txt` 는 **잃어버리면 업데이트를 못 올립니다.** 안전한 곳에 두시고 누구에게도 보내지 마십시오.
- `.aab` 를 플레이 콘솔 **내부 테스트**에 올린 뒤, 콘솔의 **SHA-256 지문**을 저에게 주시면 `assetlinks.json` 을 채워 배포합니다. (지금은 빈칸입니다)
- 따라 하기: `docs/출시/플레이-콘솔-등록-절차.md`

### ⑥ 기한 두 가지 확인 (각 2분)

- 공공데이터 인증키의 **실제 만료일** — data.go.kr 마이페이지 → 개발계정 → 활용기간 / 식품안전나라 마이페이지. 지금 알림은 추정일(2027년 8월)로 걸려 있습니다.
- 가비아에서 도메인 **자동연장** 켜기.

### ⑦ 공개 출시 — 식약처 회신 뒤

- 회신에 따라 기능·표현을 고칩니다.
- '검수용 시험 버전' 배너를 떼고 검색 노출을 풉니다(세 곳을 함께 — 제가 합니다).
- 플레이 프로덕션 출시. 심사 기간에는 서버가 멈추지 않는지 특히 봅니다.

### 애플은 그 뒤

웹을 감싸기만 한 앱은 애플이 받지 않습니다(지침 4.2). 푸시 알림 같은 기능을 따로 붙여야 하고, 소셜 로그인을 두면 'Apple 로 로그인'도 필요합니다(4.8). 플레이를 먼저 냅니다.

## 4. 선생님이 정해 주실 것

자가시험에서 나왔지만 **임상 판단이라 제가 정하지 않은 것**입니다. 지금은 모두 "현재 상태 그대로" 두었습니다.

| 무엇 | 지금 앱은 | 여쭙는 것 |
|---|---|---|
| 훈제연어 · 반숙/수란 · 프로슈토/하몽 (호중구감소 시기) | '주의' | '피하세요'로 올릴지 |
| 전복장 (호중구감소 시기) | '주의' | 게장·새우장처럼 '피하세요'로 할지 |
| 자몽과 항호르몬제 | 타목시펜·아로마타제 억제제·ADT **만** 드시는 분께는 자몽 경고가 안 뜸 | 이대로 둘지 (타목시펜은 일부가 CYP3A4 로 대사됩니다) |
| 낫토·청국장과 와파린 | '주의'라서 추천 식단에 드물게 나옴 | '피하세요'로 올려 추천에서 뺄지 |
| 상황을 전제로 한 권장 문구 | "수술적 폐경 이후에는…", "ADT 중에는…", "위 수술을 받았다면…" 이 그 상황을 고르지 않은 분께도 뜸 | 문구를 조건문으로 바꿀지, 고르신 분께만 띄울지 |
| "금기"라는 말 | "CDK4/6 억제제 복용 중 자몽은 금기입니다" | 질의서에서도 여쭙니다. 미리 "피하세요"로 고쳐 둘지 |
| 제가 잡은 문턱 | 1회 제공량에 단백질 5 g · 칼슘 80 mg 이상이어야 그 이유로 '권장' | 숫자가 적절한지 |

**정해진 것:** 자몽 '피하세요'는 항암제를 쓰는 동안에만 (10월 13일). 치료 시기가 항암치료 중·호중구감소 시기이거나,
약에서 항암제·표적치료제·먹는 항암제를 고르신 분께 뜹니다. 질의서 4-2항도 그렇게 고쳤습니다.
