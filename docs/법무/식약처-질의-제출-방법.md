## 왜 지금 내는가

- 스토어 심사 메모에 "식약처에 의료기기 해당 여부를 질의하였습니다"라고 적어 두었습니다. 실제로 내야 그 말이 사실이 됩니다.
- 회신에 따라 앱의 기능이나 표현을 고쳐야 할 수 있습니다. 출시한 뒤에 고치는 것보다 지금이 쌉니다.
- **올해 제도가 바뀌는 중입니다.** 「의료기기법」이 2026년 6월 9일 개정되어(법률 제21775호) '의료기기 해당 여부 사전검토'에
  법적 근거와 **수수료 규정**이 생깁니다. 시행규칙(안)이 9월 14일 입법예고되어 10월 26일까지 의견을 받고 있습니다(식약처 공고 제2026-445호).
  수수료 금액과 시행일은 확인하지 못했습니다. 지금은 종전 방식(질의 민원)으로 낼 수 있는 시기로 보입니다.

## 2. 창구 — 확인된 두 곳

### 가. 의료기기 전자민원시스템 `emedi.mfds.go.kr`

- **개인 회원가입이 됩니다**(개인 · 개인사업자 · 법인사업자 세 갈래).
- 신청할 수 있는 민원 목록에 **'의료기기질의'**가 있습니다. 해당 여부 질의가 이 항목인지는 확인하지 못했습니다 → 1번 전화.
- 같은 사이트에 '디지털의료·건강지원기기 민원신청' 메뉴도 따로 있습니다. 질의 4번(건강지원기기 해당 여부)과 관련이 있습니다.
- 순서: 회원가입 → 로그인 → 민원안내 및 신청 → 신청서 작성·첨부 → (수수료가 있으면) 납부 → 접수

### 나. 국민신문고 `epeople.go.kr`

- 전자민원 사이트가 '일반민원'은 이쪽으로 내라고 안내합니다.
- 본인 인증 뒤 **민원 신청 → 처리 기관을 '식품의약품안전처'로** 지정합니다.
- 개인 자격으로 내기에는 이쪽이 문턱이 낮습니다.

> 두 곳에 **같은 것을 겹쳐 내지는 마십시오.** 한쪽이 다른 쪽으로 넘겨져 처리가 늦어집니다.

## 3. 내기 전에 읽어 보실 것 (10분)

질의서는 제가 앱 자료와 한 줄씩 대조했지만, **이름을 걸고 내시는 문서이니 4항만은 직접 읽어 주십시오.**

- [ ] **4항 '민감한 기능 네 가지'** — 앱이 실제로 하는 말을 숨김없이 적었습니다. 사실과 다른 곳이 없는지
- [ ] 연락처 칸에 **전화번호** 넣기 (지금은 '제출 시 기입'으로 비어 있습니다)
- [ ] 8-2항의 웰니스 지침 사례 두 가지는 **언론 보도로 확인**한 것입니다. 식약처 누리집 → 법령/자료 → 공무원지침서/민원인안내서에서
      「의료기기와 개인용 건강관리(웰니스) 제품 판단기준」 개정본을 받아 실제로 실려 있는지 보시면 더 단단합니다
- [ ] 9항 질의 6의 「의료기기법」 제26조 제7항 — 조문 번호를 국가법령정보센터(law.go.kr)에서 한 번 확인

## 4. 민원 본문 칸에 붙여 넣을 글

온라인 민원은 본문 칸이 따로 있고 글자 수 제한이 있는 경우가 많습니다. 아래를 본문에 넣고, PDF 를 첨부하십시오.

**제목**

```
소프트웨어(암 환자용 식이·영양 정보 앱)의 의료기기 해당 여부 질의
```

**본문**

```
개인(방사선종양학과 전문의)이 개발한 소프트웨어 「하루차림」의 의료기기 해당 여부를 질의합니다.
앱 장터에 등록하기 전에 확인받고자 합니다.

[제품]
암 진단을 받은 분이 암종·치료 시기·증상·복용 약의 종류를 직접 고르면,
공개된 진료지침과 한국인 영양소 섭취기준에 실린 식생활 정보 가운데
해당하는 것을 근거 문헌과 함께 보여 주는 독립형 소프트웨어입니다.
센서·측정기기와 연동하지 않고, 검사 수치를 입력받지 않으며, 인공지능을 쓰지 않습니다.
고정된 규칙표(152건)와 공개 계산식으로만 동작합니다.
진단하지 않고, 치료 방침을 제시하지 않으며, 처방약을 권하거나 바꾸라고 안내하지 않습니다.

[경계에 있다고 보는 점]
1) 이용 대상이 암 진단을 받은 분입니다.
2) 고른 약의 종류에 따라 약물·음식 상호작용 정보를 표시합니다(28건).
3) 치료 시기·증상에 따라 같은 음식에 '피하세요'를 달리 표시합니다.
4) 기록한 식사의 영양 합계를 목표 범위와 견주어 '부족'을 표시합니다.

[질의]
1. 「의료기기법」 제2조의 의료기기 또는 「디지털의료제품법」 제2조의 디지털의료기기에 해당합니까?
2. 해당하지 않는다면 「의료기기와 개인용 건강관리(웰니스) 제품 판단기준」의 건강관리 제품으로 보아도 됩니까?
3. 위 2)~4)와 암종 가이드의 일부 문장 가운데 그 기능 때문에 의료기기로 보게 되는 것이 있습니까?
   있다면 어떻게 고치면 건강관리 제품의 범위에 듭니까?
4. 「디지털의료제품법」 제2조 제3호의 디지털의료·건강지원기기에 해당합니까? 신고 없이 유통하여도 됩니까?
5. '판정', '권장·주의·피하세요', '근거 A·B·C·G' 가운데 고쳐야 할 표현이 있습니까?
6. 앱 장터 등록 문구와 화면에 의료기기로 오인하게 할 표시·광고가 있습니까?

제품 설명 전문, 화면 6장, 규칙 152건 전체 목록, 참고 문헌 87종, 등록 예정 문구를 첨부합니다(19쪽).
```
