## 0. 질의 취지

본 제품이 「의료기기법」 제2조의 의료기기에 해당하는지, 아니면
식품의약품안전처 「의료기기와 개인용 건강관리(웰니스) 제품 판단기준」상
**개인용 건강관리(웰니스) 제품**에 해당하는지 확인을 요청드립니다.

본 제품은 암 진단을 받은 분을 이용 대상으로 하므로,
판단기준이 정한 "만성질환자의 질병 관리"와 "일상적 건강관리"의 경계에 놓일 수 있다고 판단하여
출시 전에 미리 여쭙습니다.

## 2. 사용 목적

본 제품의 사용 목적은 **공개된 진료지침과 국가 영양소 섭취기준에 근거한
일반적인 식생활 정보를 정리하여 보여 주는 것**입니다.

구체적으로 다음 세 가지를 수행합니다.

1. 이용자가 입력한 암종·치료 시기·체중·키를 바탕으로,
   **공개된 계산식**(Mifflin-St Jeor 기초대사량, ESPEN 2021 권고 열량·단백질 범위)에 따라
   하루 섭취 목표 범위를 산출하여 보여 줍니다.
2. 그 범위에 맞는 음식 조합을 예시로 제시합니다.
3. 특정 음식이나 영양제가 해당 상태에서 주의 대상인지 여부와 **그 근거 문헌**을 함께 보여 줍니다.

## 3. 수행하지 않는 것 (제품이 스스로 배제하는 기능)

「의료기기법」 제2조 각 호의 목적에 해당하지 않도록 다음을 설계 단계에서 배제하였습니다.

| 배제한 것 | 확인 방법 |
|---|---|
| 질병의 진단 | 진단·병기 판정 기능 없음. 이용자가 이미 받은 진단명을 **입력**할 뿐이며, 제품이 판단하지 않음 |
| 질병의 치료·경감·처치 | 치료 방침 제시 없음 |
| 약물의 권고·변경 | 처방약을 추천하거나 용량을 조정하는 기능 없음 |
| 검사 수치의 해석 | 혈액검사 등 검체 수치를 입력받거나 해석하는 기능 없음 |
| 생체신호 측정 | 센서·측정 기능 없음. 체중도 이용자가 직접 적는 값 |
| 응급 상황 판단 | 위험 신호를 판정하거나 응급 대응을 안내하는 기능 없음 |
| 개인별 처방 | 산출값은 공개 계산식의 결과 범위이며, 개별 환자의 임상 판단을 대체하지 않음을 화면과 약관에 명시 |

## 4. 작동 원리

본 제품은 학습형 모형이나 독자적 알고리즘을 쓰지 않습니다.
**공개된 계산식과 공개된 지침을 그대로 옮긴 규칙표**로 동작합니다.

1. **목표 산출** — Mifflin-St Jeor 식으로 기초대사량을 구하고,
   ESPEN 2021 권고 범위(25~30 kcal/kg, 단백질 1.0~1.5 g/kg 등)를 곱해 범위를 냅니다.
2. **음식 제시** — 그 범위에 가까워지도록 음식 조합을 고릅니다.
3. **주의 표시** — 규칙표에 해당하는 항목이면 주의 문구와 **출처 문헌**을 함께 표시합니다.

규칙 121건은 모두 출처가 붙어 있으며, 출처 없는 규칙은 자동 검사에서 배포가 차단됩니다.
제품은 새로운 의학적 판단을 만들어 내지 않고, 공개 문헌의 내용을 이용자 상황에 맞게 골라 보여 줍니다.

앱 첫 화면, 이용약관 전문(前文)과 제6항, 개인정보처리방침 말미에 다음을 명시하고 있습니다.

> 하루차림은 진료를 대체하지 않습니다. 이 앱이 보여 드리는 식단과 영양 정보는
> 공개된 진료지침과 영양소섭취기준을 바탕으로 만든 참고 자료입니다.
> 드시는 것을 실제로 바꾸실 때에는 담당 의료진과 상의하십시오.

> 서비스는 여러 분께 두루 맞는 참고 자료를 보여 드릴 뿐,
> 한 분 한 분의 상태를 진찰하거나 판단하지 않습니다.
> 같은 암이라도 검사 수치와 치료 경과에 따라 드셔야 할 것이 달라집니다 —
> 그 판단은 담당 의료진의 몫입니다.

## 6. 신청인의 검토 의견

「의료기기와 개인용 건강관리(웰니스) 제품 판단기준」의 판단 흐름에 비추어
다음과 같이 정리하였습니다.

| 판단 항목 | 본 제품의 경우 |
|---|---|
| 사용 목적이 질병의 진단·치료·경감·처치·예방인가 | **아니오.** 식생활 정보 제공에 한정 |
| 의료인의 진료 행위를 대체·보조하는가 | **아니오.** 진료 판단은 의료진의 몫임을 반복 고지 |
| 개인의 생체신호를 측정·분석하는가 | **아니오.** 측정 기능 없음 |
| 위해도가 있는가 | 낮음. 정보 제공에 그치며 기기 조작·투약·시술과 무관 |
| 만성질환자를 대상으로 하는가 | **예.** 암 진단을 받은 분이 대상 |

마지막 항목 때문에 판단기준상 "만성질환자의 질병 관리"에 해당할 여지가 있는지가
신청인이 스스로 결론 내리기 어려운 지점입니다.

다만 판단기준이 예시하는 만성질환 관리형 제품이
**측정값을 받아 질환의 상태를 판단하거나 치료 행위를 조정하는 것**을 가리키는 반면,
본 제품은 측정도 판단도 조정도 하지 않고 공개 문헌의 식생활 정보를 정리해 보여 주는 데 그치므로,
**개인용 건강관리(웰니스) 제품에 해당한다**고 판단하고 있습니다.

## 7. 질의 사항

1. 본 제품이 「의료기기법」 제2조의 의료기기에 해당합니까?
2. 해당하지 않는다면, 「의료기기와 개인용 건강관리(웰니스) 제품 판단기준」상
   개인용 건강관리 제품으로 보아도 되겠습니까?
3. 암 진단을 받은 분을 대상으로 한다는 점만으로 의료기기로 보게 되는 경우,
   어떤 기능을 덜어 내면 웰니스 제품의 범위에 들어옵니까?
4. 앱 안의 문구 중 **"판정"**(예: "이 음식이 지금 상태에 맞는지 판정합니다")이라는 표현이
   진단으로 오인될 소지가 있다면, 어떤 표현으로 바꾸는 것이 적절합니까?
5. 본 제품과 관련하여 「식품 등의 표시·광고에 관한 법률」상
   질병 예방·치료 효능 표방으로 볼 소지가 있는 부분이 있습니까?
